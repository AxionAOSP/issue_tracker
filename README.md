# How to Submit a Bug Report for AxionOS

Thank you for helping improve AxionOS! Before submitting a bug report, please follow these steps:

## 1. Check for Existing Issues
Before creating a new issue, check if someone has already reported the same bug. This helps avoid duplicates and speeds up the resolution process.

## 2. Open a New Issue
Navigate to the [AxionOS GitHub Issues](https://github.com/AxionAOSP/issue_tracker/issues) page and click on `New Issue`. Select the `Bug Report` template.

## 3. Fill in the Required Details
Use the provided bug report template and fill in the following sections:

- **Describe the Bug**: Clearly explain the issue.
- **Steps to Reproduce**: Provide a step-by-step guide to replicate the issue.
- **Expected Behavior**: Describe what should have happened.
- **Screenshots/Logs**: Attach any relevant screenshots or logs.
- **Device Information**:
  - Device Model
  - AxionOS Version
  - Android Version
  - Kernel Version
- **Additional Context**: Any extra information that might help diagnose the issue.

## 4. Submit the Issue
After completing the form, click `Submit new issue`. Our team will review and respond as soon as possible.

## 5. Follow Up
Check back regularly for updates or requests for additional information. You may receive questions from maintainers to help troubleshoot.

Thank you for your contribution!
